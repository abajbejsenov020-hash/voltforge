# Comparable stock and modified speed scenarios

The original bug compared the G4's advertised 70 km/h reference with a separate generic power/drag estimate for modified hardware. Selecting a 6 kW motor therefore showed 54 km/h because an assumed 40 A supply limited shaft power to 1685 W. The same factory hardware also calculated 53 km/h when forced through that generic path. These were different reference bases, not evidence that the larger motor made the scooter slower.

Modified rebuilds with a documented factory speed and power basis now use a **factory-relative planning comparison**. A scaling factor relates the stock reference speed to the original rated motor input and the model's default reference conditions (80 kg rider, original vehicle mass, calm/level road, default posture, 78% conversion assumption). The same factor is then used when solving the changed hardware with its available power, entered mass, wind and grade. If only factory peak watts are known, the existing 50%-of-peak continuous scenario is disclosed. This is a conditional comparison from an advertised reference; it is not measured aerodynamic calibration or GPS verification. The separate range-energy scenario is not fitted to the advertised maximum range or speed.

Current limits still bound available power, and an entered wheel RPM/outer-diameter ceiling still bounds speed. The UI identifies those limits instead of silently imposing a lower number. A weaker motor, entered low current, adverse wind/load or lower RPM can produce a lower speed: there is no minimum-speed clamp. A larger motor on the original battery/controller can plateau near stock because the supply cannot use its full rating. Missing winding, voltage-specific RPM or gearing remains unverified; rated watts alone never establish an exact speed. New builds and vehicles without a usable factory reference retain the absolute power-based scenario.

The regression suite covers stronger and weaker motors, matched and restricted supplies, RPM limits, wind/load, GPS priority and state immutability. One-variable probes reproduced the method switch and supply cap independently before the fix.

Physics context: [Grin's motor simulator](https://ebikes.ca/resources/web-tools/simulator.html) distinguishes battery/phase current, motor winding, controller and battery limits. [Grin's hub-motor explanation](https://ebikes.ca/resources/learn/hub-motors.html) explains why winding, voltage and wheel size affect speed. The reference-normalization method above is this app's disclosed comparison assumption, not an implementation or validation of Grin's measured motor-curve simulator.
